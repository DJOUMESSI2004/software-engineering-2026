## Basic linux commands and uses 

- ls : list elements of a given directory. e.g : ls <DirectoryPath>
- cd : move to a directory. e.g : cd <DirectoryPath>
- mv : move or rename a directory. e.g : mv <fileDirectory> <Destination> same for renaming
- cat: list value of a file directory. e.g : cat <FileDirectory>
- rm : delete file directory. e.g : rm <FileDirectory>
- pwd : show file directory path. e.g pwd <FileDirectory>
- mkdir : create file directory. e.g mkdir <NewDirectory>
- touch : create file dir. e.g touch <fileNameDirectory>
- cp : copy file directory to destination. e.g cp <FileDirectory> <CopyDestination>
